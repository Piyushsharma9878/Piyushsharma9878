> **Smart IIoT-Powered MSME Platform**

An end-to-end IIoT + Web platform that transforms offline cash-based small businesses into digitally visible, creditworthy enterprises:

* 📡 **Hardware Integration**: ESP32 sensor device automatically logging offline cash & payment events.
